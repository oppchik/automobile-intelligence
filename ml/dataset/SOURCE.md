# Источник датасета

| Параметр | Значение |
|---|---|
| Репозиторий | https://github.com/spcCodes/Car-Damage-Intensity-Detection |
| Закреплённый коммит | `9cf322a5e7bdf32c87c49b717d479d47fd44fffc` |
| Используемые папки | `task_vision/data/training`, `task_vision/data/test` |
| Классы | `minor`, `moderate`, `severe` (тяжесть повреждения автомобиля) |
| Исходный объём | 979 обучающих + 171 тестовое изображение |
| После очистки | 1136 уникальных изображений (830 train / 139 val / 167 test) |

## Что сделано с исходными данными

- Папка `task_vision2` не используется: это точная копия обучающей выборки из `task_vision`.
- Удалено 12 точных дубликатов (10 внутри обучающей выборки, 2 тестовых снимка, совпавших с обучающими).
- Исключено ещё 2 тестовых снимка — почти-дубликаты обучающих (перцептивный хэш dHash, расстояние Хэмминга ≤ 4).
- Валидационная выборка выделена из обучающей по группам почти-дубликатов, поэтому копии одного снимка не попадают в разные выборки.

## Важные ограничения

- **Лицензия в исходном репозитории не указана**, происхождение снимков и протокол разметки не описаны.
  Поэтому сами изображения **не хранятся** в этом репозитории: коммитятся только манифест
  (`manifest.csv`: путь, класс, выборка, sha256, размеры) и скрипт `ml/scripts/fetch_dataset.py`,
  который скачивает данные по закреплённому коммиту и проверяет их по sha256 из манифеста.
- Датасет размечен только по **тяжести**. Меток деталей (бампер, фара, капот…) в нём нет,
  поэтому классификация повреждённых деталей этим набором не поддерживается.
- Граница между `minor` / `moderate` / `severe` субъективна; одна группа почти-дубликатов в данных
  имеет противоречивые метки.
