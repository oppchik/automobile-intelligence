# ML: классификация тяжести повреждений по фото

Экспериментальный модуль второй итерации. Определяет тяжесть повреждения (`minor` / `moderate` / `severe`)
по фотографии и сообщает уверенность. Если уверенность ниже порога `tau`, интерфейс должен предложить
пользователю выбрать тяжесть вручную (ручной выбор остаётся резервным вариантом).

**Не решает:** определение повреждённых деталей (нет размеченных данных), поиск повреждения на фото.

## Результаты (подробности — `reports/`)

| Выборка | Accuracy | Macro-F1 | 95% ДИ accuracy |
|---|---|---|---|
| val (139) | 0.640 | 0.620 | 0.56 – 0.72 |
| test (167) | 0.683 | 0.681 | 0.60 – 0.75 |

Бейзлайны на test: ручные признаки + Random Forest — accuracy 0.563; всегда «severe» — 0.395.
С порогом `tau = 0.55` (выбран по val) на test модель сама обрабатывает 64% случаев с точностью 0.79 (на val — 69% и 0.80), остальные идут на ручной выбор.

## Запуск

```bash
conda env create -f ml/environment.yml && conda activate avto-ml
cd ml/scripts
python fetch_dataset.py        # скачать исходные фото (не хранятся в git)
python prepare_split.py        # чистка и разделение -> dataset/manifest.csv
python extract_features.py     # эмбеддинги EfficientNet-B0 (кэшируются в ml/data/cache)
python baseline_features.py    # ручные признаки для бейзлайна
python train.py                # обучение, метрики, артефакты -> models/, reports/
python predict.py photo.jpg    # инференс
```

## Структура

| Путь | Назначение |
|---|---|
| `dataset/manifest.csv` | разметка: файл, класс, выборка (train/val/test), sha256, группа |
| `dataset/split_summary.json` | статистика очистки и разделения |
| `dataset/SOURCE.md` | источник данных, лицензия, ограничения |
| `scripts/` | загрузка, подготовка, обучение, инференс |
| `models/severity_head.npz` | веса обученной «головы» (логистическая регрессия) и порог `tau` |
| `models/model_card.json` | описание модели, препроцессинга и ограничений |
| `reports/` | метрики (`metrics.json`), матрицы ошибок, кривая покрытие/точность, лог обучения |

Веса EfficientNet-B0 (ImageNet) не хранятся в репозитории: `extract_features.py` скачивает их из GitHub Releases
и проверяет контрольную сумму.
