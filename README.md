# AuInt — «Чинить или продавать?»

## Принцип проекта

Автовладелец, столкнувшийся с поломкой, вводит данные о машине (марка,
модель, год, пробег, регион, состояние до поломки) и описывает проблему
текстом, отмечает категории повреждений и/или загружает фото. Дальше сервис:

1. **Определяет категории повреждений** — шесть независимых групп (кузов,
   оптика, электроника, подвеска, двигатель, окраска) плюс скрытая категория
   «силовой каркас/рама», включаемая только автоматически по тексту описания.
2. **Считает смету ремонта** в трёх вариантах — официальный дилер,
   независимый сервис, б/у запчасти.
3. **Ищет запчасти** у нескольких продавцов с фильтрами по цене, состоянию и
   расстоянию, с отслеживанием цены.
4. **Оценивает рыночную стоимость автомобиля** — в хорошем состоянии, «как
   есть» и после ремонта.
5. **Даёт рекомендацию** — «чинить», «продать как есть» или «нужна очная
   диагностика» — и показывает точку безубыточности ремонта.
6. Сохраняет каждый расчёт в историю, привязанную к анонимному
   идентификатору сессии устройства (полноценная аутентификация — в планах).

Это MVP: расчёты сметы, цен на запчасти и рыночной стоимости построены на
демонстрационных формулах и справочных таблицах (`backend/app/data.py`,
`backend/app/engine.py`), а не на реальном парсинге объявлений или
нейросетевом анализе фото.

## Стек

- React 18 + Vite 5 (фронтенд), Cirrus-компоненты (кнопка, табы, поиск,
  чекбоксы), чёрно-бело-серая палитра с точечными функциональными цветами.
- FastAPI + SQLAlchemy (бэкенд): SQLite локально, PostgreSQL в Docker.
- PWA: манифест, service worker, устанавливается на домашний экран.
- Docker Compose: `db` (Postgres) + `api` (FastAPI) + `web` (Nginx).

Фронтенд всегда сначала обращается к API; если бэкенд недоступен, расчёт
бесшовно переключается на локальный офлайн-движок (`frontend/src/lib/engine.js`,
формулы продублированы 1:1 с бэкендом).

## Структура проекта

```
.
├── backend/
│   └── app/
│       ├── data.py       справочники: марки/модели, регионы, категории повреждений, запчасти
│       ├── engine.py     чистая расчётная логика (источник истины)
│       ├── models.py     ORM: история расчётов, отслеживаемые запчасти
│       ├── schemas.py    Pydantic-схемы запросов/ответов
│       └── main.py       FastAPI-приложение и все эндпоинты
├── frontend/
│   └── src/
│       ├── components/   cirrus.jsx, Header.jsx, CalcPage.jsx, PartsPage.jsx, HistoryPage.jsx, ui.jsx
│       └── lib/          api.js (клиент с офлайн-фолбэком), engine.js (офлайн-копия расчёта)
└── docker-compose.yml
```

## Запуск локально (без Docker)

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

```bash
cd frontend
npm install
npm run dev
```

Фронтенд на `http://localhost:5173` сам проксирует `/api/*` на бэкенд (см.
`vite.config.js`). Если бэкенд не запущен — приложение всё равно откроется и
будет работать в офлайн-режиме.

## Запуск через Docker Compose

```bash
docker compose up --build
```
- Фронтенд: `http://localhost:8080`
- API: `http://localhost:8000` (Swagger: `http://localhost:8000/docs`)
